# Telegram-бот персонального тренера

Готовый Telegram-бот: каталог тренировок, питания и онлайн-услуг с понятной inline-навигацией и быстрым переходом в Telegram тренера.

## Облачный запуск — Cloudflare Workers

Рабочая версия для бесплатного хостинга находится в `worker.js`. Она использует Telegram webhook и не требует постоянно работающего компьютера.

Для развёртывания нужны два секрета в Cloudflare Workers: `BOT_TOKEN` и `WEBHOOK_SECRET`. Они не добавляются в Git. После деплоя Telegram webhook указывается на адрес Worker.

## Локальный запуск Python-версии

1. Установите Python 3.10+.
2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. Скопируйте настройки и заполните их:

   ```bash
   cp .env.example .env
   ```

   В `.env` укажите `BOT_TOKEN`, имя и username тренера, цены, адрес и остальные данные. `TRAINER_USERNAME` вводится без `@`.

4. Запустите бота:

   ```bash
   python bot.py
   ```

## Настройка

Все пользовательские данные вынесены в `.env`: цены, формат услуг, контакты и профиль тренера. Файл `.env` не попадает в Git.

## Возможности

- `/start` открывает лаконичное главное меню;
- каждый раздел и услуга открываются inline-кнопками;
- у карточек услуг есть призыв к действию, возврат в раздел и в главное меню;
- кнопка связи ведёт на Telegram-профиль тренера.
